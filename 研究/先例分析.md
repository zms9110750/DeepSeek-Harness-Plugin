# 先例分析：别人已经做到哪一步

目标不是照抄，是**先确认哪几条不用自己发明**。

---

## 1. gawt / gitagent `[仅摘要，待读源码]`

- 链接：https://pypi.org/project/gawt/0.6.0/
- 定位：MCP-first 的 agent 工作区管理器

它已有的东西（摘要里的原词）：

| 它有的 | 对应我们哪条需求 |
|---|---|
| shared worktree | 子工作区 |
| **per-file locks**：写之前先拿锁，冲突就拒绝并告知 | 子工作区（读写锁） |
| partial snapshots | 防止外部更改（快照） |
| semantic intents（先声明意图再动手） | 异步工具 / 审批 |
| pheromone edit tracking（记录谁改过） | 防止外部更改 |

**要读的**：锁的粒度（文件？目录？）、锁的持有者是谁（进程？会话？）、快照存哪、冲突时返回什么错误。

**判断**：如果它的锁模型够用，我们就只做「把它接到 DSH 里」，不自己造。

## 2. llm-cli-gateway `[仅摘要，待读源码]`

- 链接：https://security.snyk.io/package/npm/llm-cli-gateway
- 定位：本地控制面，跨 MCP 客户端的审批闸门

它有的东西：

| 它有的 | 对应我们哪条需求 |
|---|---|
| **approval gates** | 异步工具（不阻塞的审批） |
| **durable jobs**：任务持久化，进程重启还在 | 异步工具的后半段（用户回来才决断） |
| workspace-scoped remote access | 子工作区 |
| sessions + audit receipts | 权限拦截（谁放行了什么） |

**要读的**：审批请求怎么持久化、用户回来时怎么把结果送回 agent、超时怎么办。

**判断**：这一份基本就是「异步工具」的完整先例。如果它的模型成立，需求 8 就变成"移植 + 接 DSH 审批服务"。

## 3. changli7047/DeepSeek-Harness-Plugins `[仅摘要]`

- 链接：https://github.com/changli7047/DeepSeek-Harness-Plugins
- 内容：Windows 桌面自动化（**后台截图**、元素快照、点击输入、条件等待）+ 本地 LLM 知识库
- 特点：零依赖，自带 AI 安装指引

**和我们重叠的**：我刚写的 `ui-capture` 就是"后台截图"的一个弱化版。

**要确认的**：
1. 它的截图是不是也走 PrintWindow，还是用了别的（比如 UIA / DXGI）；
2. 它有没有做**元素级快照**（对我这种只会看图的最有用）；
3. 它能不能直接把元素树喂给模型 —— 如果能，很多 UI 验证都不需要截图了。

**判断**：如果够用，我写的那颗可以退役，避免重复。

## 5. 其余

- [songzhiyin/dsh-local-model](https://github.com/songzhiyin/dsh-local-model)：本地模型直连。对我们的价值不是功能，而是**省 token 做实验** —— 狼人杀、并发压测这类实验可以跑本地模型。
- [cordisplugins/dsh-cordis](https://github.com/cordisplugins/dsh-cordis)：怎么把 harness 打包成插件，是打包方式的参考。
- [@xinvxueyuan/cordis-plugin-github](https://www.npmjs.com/package/@xinvxueyuan/cordis-plugin-github)：工具写法的好样本（`gh api` 参数数组 spawn，不经 shell）。

## 结论

| 需求 | 有没有先例 | 建议 |
|---|---|---|
| 子工作区锁 | **有**（gitagent） | 先读，能抄就抄 |
| 防止外部更改 | **有**（gitagent partial snapshots + ZMS 设计） | 两边合起来看 |
| 异步工具 | **有**（llm-cli-gateway） | 先读，重点看持久化 |
| MCP 装配 | **没有现成 dsh 客户端** | 自己写，用官方 SDK |
| 四描述符权限 | 协议里有，实现没找到 | 自己写，但语义照 MCP 规范 |
| VPN 分流 | 有工具（clash-verge-mcp），但要确认能不能做到"按调用" | 需要实验 |
| 树上下文 | **没有先例**（维护者回复也承认） | 只能自己设计，需要度量说服 |
