# 无头（headless）配置 · 位置与清理

这份是给"以后想删掉它"的人看的。记的是**这套无头测试环境用了哪些文件、删哪个会影响什么**。

## 一句话

无头 = 一个叫 `dev` 的独立 profile + 一个启动脚本 + 一份从 `app.asar` 解出来的宿主副本。
桌面版用的是 `desktop` profile，**一点不碰**。

## 怎么启动

```
X:\temp\dsh\探针\dev.ps1 "任务内容"
```

它实际执行：

```
node X:\temp\dsh\探针\asar\out\dsh\node_modules\@deepseek-ai\dsh\lib\bin.js --profile dev "任务内容"
```

独立进程、跑完就退，不碰正在跑的桌面版。

## 由哪些东西组成

| 位置 | 是什么 | 删了会怎样 |
|---|---|---|
| `C:\Users\16229\.dsh\profiles\dev\` | 配置本体：`package.json`、`cordis.patch.yml`、`cordis.yml`、`node_modules`、`pnpm-lock.yaml`（建 10/21 17:20） | 无头跑不起来；桌面版不受影响 |
| `X:\temp\dsh\探针\dev.ps1` | 启动脚本 | 少了启动入口 |
| `X:\temp\dsh\探针\asar\out\` | 从 `app.asar` 解出来的宿主副本（约 **420 MB**） | 启动脚本失效；删了要重新解压 |
| `X:\temp\dsh\探针\bin\pnpm.cmd` | 装/删插件用的 pnpm | 不能再用 `dsh plugin` 装删插件 |
| `X:\temp\dsh\探针\persist-router-probe\` | 探针：验证"能否给宿主持久化套一层分流" | 依赖它的 profile 条目会报错，先删 patch 那段 |
| `X:\temp\dsh\探针\append-probe\`、`plan-mode-probe\` | 更早的探针，只在依赖里，**没有挂载** | 没影响 |
| `X:\temp\dsh\探针\sqlite-store\` | 归档库原型：`tasks.db`、`store.cjs`、`tasks.html` | 原型数据没了 |

## 这套配置里挂载了什么

`profiles\dev\cordis.patch.yml`：

- `agent-default-model`：模型走 `cc-goat` / `deepseek/deepseek-v4-flash`
- `llm-pi-ai`：**禁用**（避免两套 pi-ai 抢路由）
- 插入 `@local/secrets-llm`：从 C# 项目的 user-secrets 文件读凭据（只存"哪个文件、哪一节"的引用，不存明文）
- 插入 `@deepseek-ai/dsh-experimental-agent-team` + `-tool-agent-team`（`forkProvider: tree-fork`）
- 插入 `@local/persist-router-probe`（分流探针，只记调用日志）

`profiles\dev\package.json` 里的 link 依赖：

```
@local/append-probe         → X:\temp\dsh\探针\append-probe
@local/persist-router-probe → X:\temp\dsh\探针\persist-router-probe
@local/plan-debug           → X:\temp\dsh\开发\plan-debug
@local/plan-mode-probe      → X:\temp\dsh\探针\plan-mode-probe
@local/plan-tree2           → X:\temp\dsh\开发\plan-tree
@local/secrets-llm          → X:\temp\dsh\开发\secrets-llm
```

## 怎么删（按顺序）

1. 先删 `cordis.patch.yml` 里 `persist-router-probe` 那一段（不删的话，下次启动会因为找不到包报错）。
2. 删依赖（或者直接跳到第 3 步把整个 profile 删掉）：

   ```
   node X:\temp\dsh\探针\asar\out\dsh\node_modules\@deepseek-ai\dsh\lib\bin.js plugin --profile dev remove @local/persist-router-probe
   ```

3. 删 profile 本体：

   ```
   C:\Users\16229\.dsh\profiles\dev\
   ```

   （`desktop` 是桌面版，`headless` / `web` 是更早就有的另外两个 profile，跟这套无关，别一起删。）

4. 删探针目录（按需）：`persist-router-probe`、`append-probe`、`plan-mode-probe`、`sqlite-store`。
5. 想省 420 MB：删 `X:\temp\dsh\探针\asar\`（整份宿主副本，可重新解出来）。

## 两个要留意的

1. **会话是共享目录**：宿主把所有会话写在 `C:\Users\16229\.dsh\sessions`（按工作目录分组，例如 `--X-temp-dsh--\session-<id>\`）。无头跑出来的会话会出现在桌面版的会话列表里，删配置不会删这些会话；要清得按 session id 单独删。
2. **凭据不在配置里**：secrets-llm 只是指到 `C:\Users\16229\AppData\Roaming\Microsoft\UserSecrets\992b82a8-.../secrets.json`，删配置不影响那个文件。
