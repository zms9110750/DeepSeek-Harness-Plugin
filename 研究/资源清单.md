### ZMS.MCP.Refactoring —— 拟定层 + 四描述符的设计稿

- 路径：`C:\Users\16229\source\OpenSourceLibrary\ZMS.MCP\src\ZMS.MCP.Refactoring`
- 状态：`[已验证]` 读了 `Tools/DraftTools.cs`、`Tools/FileTools.cs`、`plan/提案格式.md`
- 只读 `.cs`，按用户要求**不读该项目里的 `.md`**（`提案格式.md` 例外，是"树上下文"那份需求点名的）

**核心设计**（`DraftTools.cs`）：

```
track(path) → draft 凭据
    ├─ read(target, path)   → 内容 + 「破坏此文件所需的凭据」
    ├─ write/copy/move/delete → 只改拟定层，真实对象一个字节不动
    ├─ list(target=drafts)   → 列出所有拟定计划及其凭据
    └─ commit(path, draft, confirm?, credentials[]) → 预检 → 落盘
```

关键三条：

1. **凭据是流出来的，不是猜的** —— 想落盘得先有"你读过它"的凭据；
2. `commit` 分两趟：`confirm=null` 先预检（返回需哪些凭据），带齐凭据再真落；
3. 四个描述符直接写在特性上：`[McpServerTool(ReadOnly, Destructive, Idempotent, OpenWorld)]`。

**支持的目标类型**（`FileTools.Read`）：压缩包 zip/tar/tgz/zstd、结构文档 json/xml/ini、C# 项目 csproj/slnx、拟定句柄、ftp。
