# 沙盘

两个**完全隔离**的目录。各自的源码、构建脚本、数据文件。

```
inbox/    用户派活，界面冻结
work/     AI 改版，随便动
```

启动：

```
node server.mjs 52310
```

- 收件箱 → http://127.0.0.1:52310/
- 工作区 → http://127.0.0.1:52310/work

## 为什么隔离

之前两个页面从**同一份源码**生成，只是标题和 API 不同。结果我每改一次版，
用户的收件箱界面就跟着变——用户派活派到一半，界面换了。

现在拆成两个目录：

| | inbox/ | work/ |
| --- | --- | --- |
| 源码 | `_src/`（2026-10-27 21:53 版，冻结） | `_src/`（跟着我改） |
| 构建 | `build.mjs` | `build.mjs` |
| 产物 | `收件箱.html` | `工作区.html` |
| 数据 | `收件箱.json` / `收件箱-草稿.md` / `收件箱-提交记录.jsonl` | `工作区.json` / `工作区-笔记.md` |
| API | `/api/inbox` | `/api/work` |

改 `work/` 里的任何东西都不会影响 `inbox/`。

## 收件箱：用户用

**冻结在 2026-10-27 21:53 那一版**——就是用户派 GU-03 / GU-04 时的样子。

能做的事：

- 派一条（标题 / 模板 / 父任务 / 关系 / 高级设置）
- 看科技树 / 列表
- 改状态
- 编辑正文
- 底部写自由文本

落盘：

| 文件 | 内容 |
| --- | --- |
| `收件箱.json` | 列表条目 |
| `收件箱-草稿.md` | 底部自由文本 |
| `收件箱-提交记录.jsonl` | 每次保存追加时间戳快照 |

AI 读这三个文件就能拿到用户的指令，不需要复制粘贴。

## 工作区：AI 用

**我的改版试验场。** 格式随时会变，有破坏性更新时可能暂时读不出来。

比收件箱多出来的东西：

- 过滤二级菜单（状态 / 类别 / 领域，三级占文档流）
- 七种关系图例（父子 / 依赖 / 派生 / 来源 / 相关 / 约束 / 参考）
- 详情页头部重排（编号在左半行 + 类别领域两个标签，标题 19px）
- 新建时能看到「模板怎么选行动」（章节 → 行动的预览）
- 五个行动全部接入（text / markdown / ask / rank / derive）

用户在这里旁观，看到满意了再决定要不要同步给收件箱。

## 构建

两个目录各自独立构建：

```
cd inbox && node build.mjs
cd work  && node build.mjs
```

每个 `build.mjs` 都自检三件事，不合格直接抛错：

1. 标签平衡（script / html 各一个）
2. 函数不重复
3. 脚本能通过 `new Function` 解析

## 技术备注

- 服务只绑 `127.0.0.1`，不暴露到局域网
- 页面保存有 600ms 防抖
- 服务没起时（直接双击 HTML）退回内置样本并提示「本地模式」
