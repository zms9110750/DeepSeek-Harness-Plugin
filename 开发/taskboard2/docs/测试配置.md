# 测试配置（taskboard2test）

**一个独立的 dsh profile，只装 taskboard2，与日常使用的 profile 隔离。**

## 位置

```
C:\Users\16229\.dsh\profiles\taskboard2test\
```

## 为什么单独一个 profile

**开发和测试中的插件不能混进日常环境** —— 一旦把有 bug 的版本装进去，会影响正常工作。

**⇒ 隔离 profile 的好处：随时可以重置，不影响别的 profile。**

---

## 目录结构

| 文件 | 作用 |
|---|---|
| `package.json` | **12 个 `link:` 依赖**（bundle 本身 + 11 个包），以及 `dsh.profile.bundles` |
| `pnpm-workspace.yaml` | `packages: [.]` + `nodeLinker: hoisted` —— **只把自己当一个包，不把 `link:` 指向的目录当 workspace 成员** |
| `cordis.yml` | **空数组**（dsh profile root，装配由 bundle 的 patch 决定） |
| `cordis.patch.yml` | **空数组**（这个 profile 不需要额外 patch） |
| `smoke.mjs` | **冒烟测试脚本**（不启动 dsh，直接驱动 core） |
| `node_modules/` | `pnpm install` 生成 |

## `link:` 是什么意思

```json
"@local/taskboard2-core": "link:X:/temp/dsh/开发/taskboard2/packages/core"
```

**⇒ 软链，不复制文件。改源码后不用重新 install。**

**⚠ 但改了源码要重新 build**（`lib/` 是编译产物）。

## ⚠ 两个已知坑

### 坑 1：`pnpm -r build` 用不了（找不到 `tsc`）

**因为工作区没装 `typescript`。**

**⇒ 绕法：直接用 `%TEMP%\ts-probe` 里的 `tsc`：**

```powershell
$tsc = Join-Path $env:TEMP 'ts-probe\node_modules\typescript\bin\tsc'
$types = Join-Path $env:TEMP 'ts-probe\node_modules\@types'
cd X:\temp\dsh\开发\taskboard2\packages
foreach ($p in Get-ChildItem -Directory) {
  if (-not (Test-Path (Join-Path $p.FullName 'tsconfig.host.json'))) { continue }
  Push-Location $p.FullName
  node $tsc -p tsconfig.host.json --typeRoots $types
  Pop-Location
}
```

### 坑 2：`@deepseek-ai/schemastery` 与 `cosmokit` 版本不匹配

**dsh 自带的 `schemastery@3.18.5` + `cosmokit@1.8.2` 组合有问题：**
```
The requested module '@deepseek-ai/cosmokit' does not provide an export named 'createVolatile'
```

**⇒ `schemastery@3.18.5` 需要 `cosmokit ~1.8.6`，而 dsh 带的是 1.8.2。**

**⇒ 解决办法：让 `store` / `action` / `types` / `ui` 的 `node_modules` 指向 `desktop` profile 里那套配套版本：**

```powershell
$desktopAi = 'C:\Users\16229\.dsh\profiles\desktop\node_modules\@deepseek-ai'
foreach ($pkg in @('store','action','types','ui')) {
  $nm = "X:\temp\dsh\开发\taskboard2\packages\$pkg\node_modules\@deepseek-ai"
  New-Item -ItemType Directory -Path $nm -Force | Out-Null
  foreach ($dep in @('schemastery','cosmokit')) {
    $link = Join-Path $nm $dep
    if (Test-Path $link) { Remove-Item $link -Recurse -Force }
    New-Item -ItemType SymbolicLink -Path $link -Target (Join-Path $desktopAi $dep) -Force | Out-Null
  }
}
```

**⚠ 这些链接在 `.gitignore` 里（`node_modules/`），不进版本库 —— 换机器要重建。**
