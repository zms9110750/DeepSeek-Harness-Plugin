# 派生按钮的初始化行为

**这是代码里写死的行为，模板不参与。**
**模板的 `derive` 只提供三项：`label`、`description`、`template`。**

---

## 点下一个派生按钮时发生什么

1. **模板** = 该按钮的 `template` 指向的模板
2. **父任务** = 当前卡（点按钮的那张）
3. **标题** = `父任务标题` + `-` + `按钮label`
4. **关系** = `parent` 设为父任务

**⇒ 三样都只是「初始化」。**

---

## 标题规则

```
标题 = {父任务标题}-{按钮 label}
```

**`label` 缺失时，用模板的显示名（`displayName`）代替。**

**例：**
| 父任务标题 | 按钮 label | 新卡标题 |
|---|---|---|
| 做个登录页 | 拆成设计 | `做个登录页-拆成设计` |
| 做个登录页 | （无 label） | `做个登录页-决策` |

---

## ⚠ 只有初始化时算一次

**中途把模板改掉，标题不会跟着变。**

**⇒ 标题一旦生成就是普通文本，之后由用户自己改。**

---

## 模板里不再有变量

**`{{ title }}` / `{{ parent }}` / `{{ kind }}` / `{{ domain }}` 全部作废。**

**⇒ 模板的 `derive` 只剩：**

```yaml
derive:
  - label: 拆成设计
    description: 需求还不清楚，先开一张决策卡把方向摆出来
    template: decision
```

**`title` 和 `relations` 两个字段从模板语法中删除** —— 它们由代码按上面的规则生成。
