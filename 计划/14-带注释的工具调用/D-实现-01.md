# D-实现-01

## 实现

1. 监听 `tools/post-execute`，`next()` 之后拿到决定
2. 若 `decision.kind === 'accept'` 且没有 `value`（PTC 路径），追加 `{type:'text', text:'#n'}`
3. 同时把 { n, name, args, ok, content } 存进会话级 Map（上限 200 条）

## 踩过的坑

- **不能用 `presentCall`**：`dsh-tools` 的 README 明确写 Web 客户端不消费它。
- PTC 形态的 accept 带 `value`，改写 content 会丢掉规范值 —— 遇到就跳过。

## 还差

界面显示。需要 `tool.call.toolview` 渲染器，或在折叠行头加徽标。属于要讨论的呈现方式。
