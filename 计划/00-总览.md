# 计划总览

状态：**起草**（对应 `todo/` 里的 14 份需求）

## 一、这些需求其实是三个机制 + 十个用法

| 机制 | 用一个词说 | 服务于 |
|---|---|---|
| **拟定层** | 先记下要改什么，真东西不动，最后一次落盘 | 防止外部更改、压缩包工具、删除工具 |
| **调度器** | 谁占了哪块地，排队多久 | 子工作区、并发 agent |
| **非阻塞等待** | 不决断就挂起，不卡死循环 | 异步工具、权限拦截 |

## 四、贯穿所有项的三条硬约束

1. **不要烧 token 做真实验**。狼人杀、长任务压测，一律用最小样例。
2. **不要用子 agent 做调研**（用户明确要求），自己读。
3. **本机沙箱目前是坏的**：confined 模式所有命令失败（`temp grant materialization`），任何 `git`/`pnpm`/`pwsh` 都要一次性完全权限。

## 五、每份计划的格式

沿用 `ZMS.MCP.Refactoring/plan/提案格式.md`：

- **A 问题**：痛点 / 验收 / 适用性 / 先例
- **B 设计**：主要目标 / 次要目标 / 约束与许可 / 可用工具
- **C 接口**：功能 / 暴露 / 待议
- **D 实现**：技术选型 / 细节 / 魔数
