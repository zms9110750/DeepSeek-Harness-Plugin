## C系列-接口（C-03-01）· 计划树面板（右侧工具栏）

- 功能
  - 右侧工具栏新增一个页签「计划」，里面是**计划树**，不是文件列表。
  - 树的结构：按层分组 → 每层下是计划节点 → 派发过的计划下面挂它的分支（子会话）。节点带状态：草案 / 计划 / 进行中 / 完成 / 失败 / 搁置 / 搁置草案。
  - 选中一个节点：下方（或右侧）显示正文预览，可就地读完；旁边是动作按钮「采纳」「否决」「搁置」。
  - **用户可以自己写计划**：面板里新建一份草案（填标题、选层、写正文），提交后**登记成一条日志记录（不落盘）**，和模型写出来的走同一条记录——此后它在同一个树里、用同一套状态。
  - 交互形态参照 `ask`（用户问题面板）：选中即展开、动作就地、不需要回到对话里说一句。
- 暴露
  - 用户看到的：
    - 顶部：层筛选 + 状态筛选（默认隐藏"搁置草案"）。
    - 主体：树，每行 = 状态点 + 标题 + 层 + 时间。
    - 选中行展开：正文预览（可滚动、可复制），底部三个按钮。
    - 「新建计划」：一个轻表单——标题、层（下拉，选项来自模板）、正文（markdown 文本域）。提交即写文件 + 登记。
  - 模型看到的：没有新增工具。它照旧 `plan_write` / `plan_adopt` / `plan_dispatch`；面板是同一批命令的另一个入口，两边写的是同一批记录。
  - 基准：以**计划**为基准。文件是正文，树是计划本身；分支挂在计划下面，不单独成树。
- 待议（已决，0.15.0 落地）
  - 用户写的计划标 `author: 'user'`（记录里），面板行尾显示「我」——模型看得见"这不是我写的"。
  - 新建计划的正文在面板里直接写（文本域）；宿主按模板生成骨架，写进去的是内容。
  - 树只读 `planTree` 投影，**不扫** `计划/` 目录：未登记的文件不出现在树里。补扫是以后的事。
  - **计划正文存在会话日志里**（`op:'plan'` 的 `body`），不是文件：只读会话也能记计划，因为它不动工作区；正文也不进上下文。要文件是另一次显式导出（未做）。
  - 动作后不收起预览：正文留在原位，方便对照"我刚采纳的是哪一份"。
  - 刷新靠投影变化自动重渲染；「重读」只重新读正文（文件可能被人手改过）。
  - 客户端插件**首次**获得客户端半边必须换包名（宿主把包清单缓存到重启），之后改内容刷新页面即可。这条已写进 `开发/插件变更与回滚.md`。
