## D系列-实现（D-01-01-01）· 一个宿主插件，投影 + 三个工具

> **这份文档只作为 0.7–0.16 那一版实现的历史记录。**
> 0.17 起改成一个包十个插件（`开发/plan-tree/src/`，每个插件一个 loader entry）：
> 投影从 `planTree` 拆成 `plans`（记录）+ `nodes`（派发节点），工具四个、命令六条，
> 计划正文也不再落盘（见 B-04），可写范围见 B-05。
> 下面「事件写入的三条铁律」**仍然有效**，其余字段名与文件位置都已过时。

- 工具
  - 包：`发布/plan-tree`（`@local/plan-tree`，宿主侧，无客户端半边）
  - 文件：`package.json`、`cordis.patch.yml`、`index.js`、`node_modules`
  - 依赖服务：`tools`、`commands`、`sessionProjections`、`agents`
  - 直接依赖：`zod`、`@deepseek-ai/dsh-tools`、`@deepseek-ai/dsh-session`、`@deepseek-ai/dsh-llm`
- 细节
  - 投影 key `planTree`，状态 `{ nodes, counts, nextId }`；节点字段 `id / parentSession / type / layer / topic / reason / status / childId / verdict / summary`。
  - **只写一种事件**：`plugin:plan-tree/node`，数据里带 `op: 'dispatch' | 'file'`。写入只走一个函数 `appendNode()`，它调用 `appendPluginRecord`。
  - 计数在 `op:'file'` 时改：否决 +1、成功归零、搁置不动。
  - 派发：先 `appendNode(...,'dispatch')` 把事件写进父日志，再 `buildForkSeed(session.snapshotEvents(), 最后一条 seq)` 拼种子，再 `ctx.agents.create({ sessionId, parentAgent, meta:{ parentSession, origin:'subagent', isSeeded:true, delegationDepth }, seed, inheritedEventCount, setup })`。子因此看得见自己的节点。
  - 子会话 `origin:'subagent'`，不进会话列表；工作区由 `cwd` 写死。
  - 回传：子 `whenIdle()` 后取最后一条 `assistant/message` 的文本块，作为 `user/message` 发回父：`source = { kind:'subagent-settled', form:'notice', summary: 首行≤120字, senderSessionId: 子id }`。界面据此渲染成折叠的「子任务状态更新」，不与用户发言混排。
  - 失败兜底：`agents.create` 抛错时补一条 `op:'file', verdict:'shelved'`，不留永远 open 的幽灵节点。
  - 闸门顺序：研究不能派计划 → 层存在 → 深度（等深要递归声明）→ 计数。
- 事件写入的三条铁律（两次事故换来的）
  1. **插件自有事件必须走 `appendPluginRecord`**。它会强制 `plugin:` 命名空间并标 `ignorable:true`；不认识的读端保留并跳过。
  2. **不要用 `session.append` 写自定义类型**。那样写出的是"未知且不可忽略"的类型，加载器会**拒绝解释整份日志**（`contains event type … unknown to this harness and not marked ignorable`），会话打不开，重启无效。
  3. **不要凭空造面事件类型**。`system/message`、`developer/message`、`assistant/message`、`tool/result` 都是步骤内事件，`turn`/`step` 必须等于当前打开的步骤；异步回传时没有打开的步骤，写进去必炸。`user/message` 是唯一不受步骤约束的面事件。
  4. 一种事件带 `op`，不要一个动作一个类型——类型表越小，越不会漏。
- 魔数
  - `LAYERS = ['A','B','C','D']`：模板的默认层序，只用来比较先后。
  - `MAX_REJECTIONS = 3`：同层连续否决上限。
  - `RECURSIVE = []`：允许自派同层的层名，空即全禁。
  - 节点 id 形如 `n1`，取投影里的 `nextId`。
  - `WRITE_TOOLS`：`write/edit/pwsh/bash/delete`。
- 已核实
  - 非法层被拒（`layer must be one of A/B/C/D`）、对不存在的节点结算被拒（`no node "n99"`）。
  - 子会话日志里含自己的 `plugin:plan-tree/node`；子内 `plan_tree` 能看到自己那一行。
  - 回传消息带 `source.kind='subagent-settled'`，界面渲染成折叠行。
  - 新写入的记录：`type=plugin:plan-tree/node`、`ignorable=true`。
