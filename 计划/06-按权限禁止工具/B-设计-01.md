# B-设计-01：四开关 + 一个总闸

```yaml
主要目标:
  - 每个工具四个开关：可写 / 可破坏 / 幂等 / 外部
  - 一个总闸：打开后任何工具都不许调用（连读文件）
次要目标:
  - 按 server 批量设置；审计记录；可读的拒绝理由
约束:
  - 拦截必须在 tools/pre-execute 或 guard 阶段，不能等执行后
  - 总闸要能拦住只读工具，这与普通 deny 列表不同
工具:
  - ctx.tools.guard()（同步、单调）
```

## 现状

总闸已经实现（`gate-switch2`），四开关未开始 —— 因为注解来自 MCP，得先有 05。
