# 接口

## 用户看到什么

设置里多一页"外部工具"：贴一段 JSON、一行命令、或一个 https 地址，就能加一个 server。
加完能看到它有几个工具、走的什么 transport、当前是连着还是断着。

## 模型看到什么

只有一个工具，四种动作：

    列出      —— 有哪些 server（不启动进程）
    查看      —— 某个 server 的工具与 schema
    调用      —— 对某个工具发起调用
    拒绝      —— 明确不接这个

## 为什么这样最自然

用户的操作和"加一个书签"同构；模型的操作和"打开一个工具目录"同构。
两边都不需要知道 MCP 的协议细节。
