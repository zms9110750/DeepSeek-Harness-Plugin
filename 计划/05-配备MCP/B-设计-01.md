# B-设计-01：一个稳定代理，不逐工具映射

```yaml
主要目标:
  - 只注册一个 use_capability 工具：action = list | inspect | call | decline
  - MCP 的连接、schema 缓存、工具清单全在宿主侧，不进模型可见的工具表
次要目标:
  - 按需启动进程（批准之后才起）
  - 每个 server 一个独立授权身份，可精确禁止
约束:
  - provider 可见的工具表不能随 MCP 清单变化（KV 缓存）
  - 参数是任意 JSON，而 DSH 的参数 schema 是强类型 DSL
工具:
  - @modelcontextprotocol/sdk（官方，Tier 1）
```

## 为什么否掉"每个 MCP 工具注册成一个 DSH 工具"

装一个 server 就改一次工具表 → provider 前缀变化 → KV 缓存全废。
Reasonix 明确为了避免这个才做代理。

## 待解决

`action: call` 的 args 是任意 JSON；DSH 的 schema DSL 需要 `json` 类型或字符串编码，要试哪种能过校验。
