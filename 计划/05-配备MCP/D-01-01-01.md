# 实现

## 怎么做的

- 官方 TypeScript SDK 做客户端，stdio 与 http 两种 transport
- 工具清单与 schema 缓存在宿主侧；模型侧只暴露那个代理工具
- 进程在授权通过之后才启动

## 关键决定

- **不把工具塞进模型可见的表**：这是为了前缀稳定，不是为了省事
- 每个 server 一个独立授权身份，可以精确禁掉某一个
- 调用参数是任意 JSON，而工具参数 schema 是强类型 —— 这一层要单独处理

## 还没做

- 依赖安装（插件目录要自带 node_modules）
- 用 `--dump-config` 干跑验证 transport 配置
- 量一下"工具表变化"对前缀的实际影响，用来证明代理方案的价值
