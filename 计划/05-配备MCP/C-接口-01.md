# C-接口-01

```
use_capability(
  action: 'list' | 'inspect' | 'call' | 'decline',
  server?: string,
  tool?: string,
  args?: json
) -> { text }
```

设置页对应的操作（同一套宿主方法，两个调用者）：

```
list    -> 未启动的 server 也列出（不启动进程）
inspect -> 已连接 server 的实时工具 / 未连接给缓存 schema
call    -> 目标 server 或它的某个工具
```

## 待议

- 工具是否默认进模型可见表（倾向：不进，只走代理）
- 单 server 工具上限（先定 128）
