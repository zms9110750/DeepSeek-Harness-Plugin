## A系列-问题

- 痛点/验收
  - 自定义工具基本都是 MCP 服务，而这边只有"资源登记"，没有连接器，外部工具接不进来。
  - 做到"设置里能加一个 MCP 服务（JSON / 一行命令 / https 地址），看得到工具数与 transport，能连能断"才算满意。
- 适用性
  - 基于"server 能起子进程或能出网"；stdio 受沙箱约束，http 受网络与代理约束。
  - 如果所有 server 都是纯 stdio 且沙箱不允许起进程，这个提案在当前环境里无法落地。
- 先例
  - 同类产品（Reasonix）用"一个稳定代理 + 按需启动 + 精确授权"。
  - 可抄其形；不能抄的是它自己的工具命名与内部协议。
