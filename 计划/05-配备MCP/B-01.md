## B系列-设计（B-01）

- 主要目标
  - 只注册一个稳定代理工具，四种动作：列出 / 查看 / 调用 / 拒绝。
  - 连接、schema 缓存、工具清单全在宿主侧，不进模型可见的工具表。
- 次要目标
  - 进程按需启动：授权通过之后才起。
  - 每个 server 一个独立授权身份，可精确禁用。
- 约束/许可/缺点
  - 工具表不得随 MCP 清单变化（KV 缓存是钱）。
  - 允许牺牲"模型直接看见工具名"的体验，换取前缀稳定。
  - 缺点：模型要先"列/查"才能调到目标工具，多一轮交互。
- 工具
  - 官方 TypeScript SDK；stdio 与 http 两种 transport。
