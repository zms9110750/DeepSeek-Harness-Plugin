# B-设计-02：一张卡 + 官方浏览器 tab

```yaml
主要目标:
  - 右侧栏「开始」页多一张卡，点它在内置浏览器里打开 chat.deepseek.com
次要目标:
  - 登录态与内置浏览器一致（同一个 webview）
约束:
  - 不自己写容器、不嵌 iframe（会被 X-Frame-Options 挡）
  - 不改动官方的三个卡片
工具:
  - ctx.sidebarRightTabs.register（tab 类型 + guide 条目）
  - 卡片内的 props.useTabInfo().tab.actions.openTab(kind, options)
```

## 为什么否掉 B-01

B-01 假设要"复用面板 / 自己写容器"，所以先要搞清 iframe 还是 webview。
实际发现：桌面端的浏览器页用的是真 webview（`globalThis.dshDesktop.browser`），
而且它接受 `navigation.params.url`。所以只要**一张卡指向浏览器 kind** 就够了，不必自建页面。
