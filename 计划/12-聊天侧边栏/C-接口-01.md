# C-接口-01

```
card(点击) -> tab.actions.openTab('browser', {
                 params: { url: 'https://chat.deepseek.com' },
                 replaceTab: true
               })
```

- `browser` 是官方浏览器页的 kind
- `params.url` 被浏览器页读取为初始地址
- `replaceTab: true` 让开始页让位给打开的页面

## 卡片拿到的 props

```
{ entryId, kind, title, description, useTabInfo }
```
