# 实现

## 怎么解析

不按行、不用 DOM，按**标签出现顺序**扫描三种记号：开层、闭层、文件夹名、链接。
行解析会被换行坑，DOM 遍历在不同实现下行为不一致（同一段逻辑在另一套 DOM 里跑出 0 条）。

## 关键决定

- 每个节点只存一个 `entries` 数组，条目与子文件夹**按源顺序交错**。
  分成两个数组会让所有文件夹被顶到条目后面，顺序全乱。
- 条目的 React key 用**序号**，不用 URL：导出文件里有几十条重复 URL，用 URL 当 key 会重复挂载，
  反复开合"越点越多"。
- 根节点没有名字，折叠判断会把它当收起 —— 根必须强制展开。
- 导入是**整体替换**，保序、保重复；但加载时检查「我的收藏」，缺了就补回来。

## 验证方式

解析器先在 Node 里跑通并输出 JSON（条数、文件夹数、顶层顺序），界面结果必须与之逐项一致。
一致才算完成 —— 界面侧出问题，一定是渲染而不是解析。
