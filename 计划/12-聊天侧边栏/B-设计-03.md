# B-设计-03：自控页面 —— 收藏夹

```yaml
主要目标:
  - 右侧栏第四个入口「收藏」，点进去是我们自己渲染的页面
  - 支持导入浏览器导出的收藏 HTML（Netscape 格式），保留文件夹分组
次要目标:
  - 搜索、全展开/收起、增删
约束:
  - 不嵌第三方页面（那是浏览器 tab 的事）
  - 解析必须可离线验证：解析器在 Node 里能跑出和界面一致的结果
工具:
  - ctx.sidebarRightTabs.register（tab 类型 + guide 条目）
  - tab.actions.openTab('browser', { params: { url } })（点书签开浏览器）
  - localStorage（local.bookmarks.v8）
```

## 数据结构

树：`{ name, entries: [...] }`，`entries` 里 `item` 与 `child` **按源文件顺序交错**。

## 放弃的做法

- 扁平分组（`父 / 子 / 孙` 拼成一个名字）：层级一深就不可读，且顺序被拍平。
- 用 DOM 遍历 `<DL>`：换成 linkedom 跑同一段逻辑直接得 0 条，不可靠。
