# 设计

## 这个问题背后是什么

"删除"是不可逆动作。模型手里的删除能力，等于把不可恢复的权力交给一个会犯错的执行者。

真正要的不是"能删"，是**把不可逆降级成可逆**。

## 牵连着什么

- 回收站 API 只在某些位置可用（本地盘可以，网络盘、部分挂载点不行）
- "进不去就不删"意味着工具必须有失败语义，而不是尽力而为
- 删除工具一旦存在，就会有人拿它清理目录 —— 那它必须可批量、能报告

## 要不要顺带做别的

不做。批量、撤销列表都是锦上添花，先把"永不永久删除"这一条做死。

## 放在架构哪一层

模型工具层，一次调用一个路径。
